# 距離チェック実行不可 不具合ナレッジ

発生日: 2026-08-16
対象: Campsite Design Tool / 距離チェック
状態: 解決済み

## 症状
- 「距離チェック実行」を押しても結果が表示されず、処理が進まない。
- iPhone Safariで距離チェック画面上部に大きな空白が発生する。
- 実行前から空の距離チェックマップ領域が表示され、画面が不自然に伸びる。

## 原因
1. 50m方針対応で追加した距離チェック結果UI補正処理で、`MutationObserver` が結果DOMの更新を再検知し続ける可能性があった。
2. 結果補正処理が同じ判定カードを再度書き換える経路があり、UI更新がループする可能性があった。
3. `#distanceMap` が実行前から表示されていたため、iPhone Safariでは大きな黒い空白として見えていた。
4. 修正後に関連JavaScriptのキャッシュ番号更新が不足し、Safariで旧JSが残るケースがあった。

## 対応
- `js/poi-spacing-policy-ui.js` に再補正防止ガードを追加。
- 距離チェック結果の旧40m表記を現行50m方針へ整理。
- 実行前の空マップを非表示化。
- 距離チェック開始時に「距離を計算しています…」を表示。
- 処理中の連続実行を防止。
- 完了後に結果位置へ自動スクロール。
- JavaScriptエラー時は画面上にエラー内容を表示するよう改善。
- 関連JSのキャッシュバージョンを更新。

## 確認結果
- iPhone Safari上で距離チェックが正常に実行できることを確認。
- 大きな空白表示も解消。

## 再発防止
距離チェック関連の改修時は、以下をリリース確認に含める。

- 距離判定ロジック
- 結果UIのDOM監視・再描画
- iPhone Safariでの表示
- 実行前/実行中/完了/エラーの各状態
- キャッシュバージョン更新
- main反映後の実機確認
