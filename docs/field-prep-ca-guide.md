# 現地モード準備 CA向け操作説明書

版: v0.3  
対象: Campsite Lab 現地モード準備 / 第1〜3段階

## この機能で何ができる？

現地へ行く前に、調査に使うCSVをまとめて読み込み、今回調査する公園などの範囲だけにPOIを絞り込み、そのまま現地モードへ進めます。

現在できること:

- CSVを複数まとめて選択する
- 同じPOIが複数CSVにある場合、重複を自動整理する
- ポケストップ / ジム / パワースポットの件数を確認する
- 地図上で「今回調査する範囲」を囲む
- 範囲内 / 範囲外のPOI件数を確認する
- 前回の準備状態を同じ端末で復元する
- 範囲内POIだけを、そのまま現地モードへ引き継ぐ
- 必要な場合は実験用KMLを手動保存する

## 事前に用意するもの

- 調査対象周辺のPOIが入ったCSV
- Campsite Labを開ける端末

CSVは1個でも複数でも構いません。

## STEP 1 CSVを読み込む

1. `現地モード準備` を開きます。
2. `CSVをまとめて選択` を押します。
3. 調査に使うCSVを選びます。複数選択できます。
4. 選択したファイル名を確認します。
5. `CSVを読み込む` を押します。

### 読み込み後に確認する数字

- **読込CSV**: 正常に読み込めたCSVの数
- **読込POI**: CSVから読み込んだPOIの合計
- **重複**: 同じPOIとして自動整理した件数
- **準備対象**: 重複整理後に残ったPOIの数

その下に、ポケストップ / ジム / パワースポットの件数が表示されます。

## STEP 2 今回調査する範囲を囲む

1. CSVを読み込むと地図が表示されます。
2. `調査範囲を描く` を押します。
3. 地図を動かし、中央の十字を公園などの外周に合わせます。
4. `地図中央を追加` を押します。
5. 外周に沿って3点以上追加します。
6. 間違えた場合は `1つ戻す` を押します。
7. 囲めたら `この範囲で確定` を押します。

確定すると、次の件数が表示されます。

- **準備対象**: CSV重複整理後の全POI
- **範囲内**: 今回の調査対象にするPOI
- **範囲外**: 今回は調査対象にしないPOI

範囲外POIは元データから削除されません。今回の現地モード用データから外れるだけです。

## STEP 3 現地モードを開始する

調査範囲を確定したら、`現地モードを開始` を押します。

範囲内のPOIだけを使った現地モードが自動で開きます。

この操作では、いったんKMLを保存してから選び直す必要はありません。

現地モードが開いた後は、これまでの現地モードと同じように作業します。

- POIを確認する
- 新しいPOIを設置する
- 位置を調整する
- メモや写真を残す
- 活動範囲を作る
- 距離を確認する
- 戻る / 進むを使う

現地モード側の自動保存も、従来と同じ仕組みを使います。

## 調査範囲と活動範囲は同じ？

**別のものです。**

- **調査範囲**: CSVから今回どのPOIを現地調査対象にするか決めるための範囲
- **活動範囲**: キャンプサイト設計で使用する正式な活動エリア

調査範囲は、現地モードへPOIを絞り込むためだけに使います。完成KMZへは出力しません。

活動範囲は、現地モードへ入った後に別途作成します。

## 前回の作業を続ける

CSVを読み込んだ準備データと確定した調査範囲は、この端末のブラウザ内に保存されます。

同じ端末・同じブラウザで現地モード準備を開くと、前回の状態を復元します。

現地モードへ入った後の作業は、既存の現地モード用自動保存へ引き継がれます。

サーバーやSupabaseへの保存は行いません。

## 自動引き継ぎがうまくいかない場合

現地モードには従来の `KMZ / KML / ZIP` ファイル選択を残しています。

自動引き継ぎが使えない場合でも、準備画面の `現地モード用KMLを保存（実験）` を使い、そのKMLを現地モードで手動選択できます。

## よくある質問

### 同じPOIが複数CSVに入っていたら？

重複として自動整理します。準備対象には1件だけ残ります。

### CSVを間違えて選んだら？

`選択をクリア` を押して、もう一度選び直してください。準備データと調査範囲もリセットされます。

### 調査範囲を間違えたら？

`やり直す` を押し、もう一度囲んでください。

### 現地モードを開いたら調査範囲Polygonも表示される？

表示しません。調査範囲はPOIを絞り込むためだけの一時的な範囲です。

## 現在まだできないこと

v0.3では、次の機能はまだありません。

- 追加POIの正式レイヤー自動振り分け
- 30m円の必要時だけの追加
- 提出用完成KMZの最終生成
- Google Form申請

機能追加に合わせて、この説明書も更新します。
