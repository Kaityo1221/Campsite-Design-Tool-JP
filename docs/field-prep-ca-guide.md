# 現地モード準備 CA向け操作説明書

版: v0.2  
対象: Campsite Lab 現地モード準備 / 第1〜2段階

## この機能で何ができる？

現地へ行く前に、調査に使うCSVをまとめて読み込み、今回調査する公園などの範囲だけにPOIを絞り込めます。

現在できること:

- CSVを複数まとめて選択する
- 同じPOIが複数CSVにある場合、重複を自動整理する
- ポケストップ / ジム / パワースポットの件数を確認する
- 地図上で「今回調査する範囲」を囲む
- 範囲内 / 範囲外のPOI件数を確認する
- 前回の準備状態を同じ端末で復元する
- 実験用として、範囲内POIだけの現地モード用KMLを保存する

## 事前に用意するもの

- 調査対象周辺のPOIが入ったCSV
- Campsite Labを開ける端末

CSVは1個でも複数でも構いません。

## STEP 1 CSVを読み込む

1. `現地モード準備` を開きます。
2. `CSVをまとめて選択` を押します。
3. 調査に使うCSVを選びます。複数選択できます。
4. 選択したファイル名を確認します。
5. `CSVを読み込む` を押します。

### 読み込み後に確認する数字

- **読込CSV**: 正常に読み込めたCSVの数
- **読込POI**: CSVから読み込んだPOIの合計
- **重複**: 同じPOIとして自動整理した件数
- **準備対象**: 重複整理後に残ったPOIの数

その下に、ポケストップ / ジム / パワースポットの件数が表示されます。

## STEP 2 今回調査する範囲を囲む

1. CSVを読み込むと地図が表示されます。
2. `調査範囲を描く` を押します。
3. 地図を動かし、中央の十字を公園などの外周に合わせます。
4. `地図中央を追加` を押します。
5. 外周に沿って3点以上追加します。
6. 間違えた場合は `1つ戻す` を押します。
7. 囲めたら `この範囲で確定` を押します。

確定すると、次の件数が表示されます。

- **準備対象**: CSV重複整理後の全POI
- **範囲内**: 今回の調査対象にするPOI
- **範囲外**: 今回は調査対象にしないPOI

範囲外POIは元データから削除されません。今回の現地モード用データから外れるだけです。

## 調査範囲と活動範囲は同じ？

**別のものです。**

- **調査範囲**: CSVから今回どのPOIを現地調査対象にするか決めるための範囲
- **活動範囲**: キャンプサイト設計で使用する正式な活動エリア

調査範囲は、完成KMZへ出力しません。

## 前回の作業を続ける

CSVを読み込んだ準備データと確定した調査範囲は、この端末のブラウザ内に保存されます。

同じ端末・同じブラウザで現地モード準備を開くと、前回の状態を復元します。

サーバーやSupabaseへの保存は行いません。

## 現地モード用KMLを保存（現在は実験手順）

調査範囲を確定すると `現地モード用KMLを保存（実験）` が使えるようになります。

このKMLには、調査範囲内のPOIと40m基本距離円を入れます。**調査範囲そのものは入れません。**

現在は自動引き継ぎ前の確認段階なので、保存したKMLを既存の現地モードで手動選択して動作確認します。

将来、自動引き継ぎが完成したら、この手動保存手順は説明書から削除する予定です。

## よくある質問

### 同じPOIが複数CSVに入っていたら？

重複として自動整理します。準備対象には1件だけ残ります。

### CSVを間違えて選んだら？

`選択をクリア` を押して、もう一度選び直してください。準備データと調査範囲もリセットされます。

### 調査範囲を間違えたら？

`やり直す` を押し、もう一度囲んでください。

## 現在まだできないこと

v0.2では、次の機能はまだありません。

- 現地モードへの自動引き継ぎ
- 追加POIの正式レイヤー自動振り分け
- 30m円の必要時だけの追加
- 提出用完成KMZの最終生成
- Google Form申請

機能追加に合わせて、この説明書も更新します。
